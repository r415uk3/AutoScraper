# KBTU AutoScraper

Автоматическая отметка посещаемости на портале KBTU Registration Online.

## Установка (Windows)

### 1. Установи Python

Скачай с [python.org](https://www.python.org/downloads/). При установке **обязательно** поставь галочку "Add Python to PATH".

### 2. Запусти установку

Дважды кликни `install.bat`. Он создаст виртуальное окружение, установит зависимости и скачает Chromium.

### 3. Настрой конфигурацию

`.env` — скопируй `.env.example` в `.env` и впиши токен Telegram-бота (создай бота у [@BotFather](https://t.me/BotFather) командой `/newbot`):

```
TELEGRAM_BOT_TOKEN=your_token_here
```

Остальные настройки в `.env` необязательны (значения по умолчанию — в `.env.example`):

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `ACTIVE_DAYS` | `1-6` | Дни работы: 1 = Пн … 7 = Вс. Пусто — каждый день |
| `ACTIVE_HOURS` | `07:30-21:30` | Часы работы (время ПК). Пусто — круглосуточно |
| `REFRESH_INTERVAL` | `35` | Пауза между проверками, сек |
| `RETRY_DELAY` / `MAX_RETRY_DELAY` | `30` / `300` | Задержка перезапуска после ошибки (растёт до максимума) |
| `LOGIN_MAX_ATTEMPTS` | `3` | Попыток входа подряд |
| `ALERT_REPEAT_INTERVAL` | `3600` | Одинаковое Telegram-уведомление об ошибке — не чаще раза в N сек |

`users.json` — список пользователей:

```json
[
  {
    "username": "student1",
    "password": "password1",
    "telegram": "@aidar_k"
  }
]
```

`telegram` — Telegram @username человека, которому принадлежит аккаунт. Можно не указывать — тогда уведомлений не будет.

## Telegram-бот

Бот пишет каждому лично, а не в группу. Telegram не даёт боту писать первым, поэтому:

1. Добавь `"telegram": "@username"` человеку в `users.json` и перезапусти скрипт
2. Человек открывает бота и нажимает **Start** (`/start`) — бот узнаёт его по @username и запоминает чат
3. С этого момента уведомления приходят ему в личку

Связки хранятся в `bot_state.json` (создаётся сам). Если поменять или убрать `telegram` у пользователя в `users.json`, старая связка удалится при следующем запуске. Команды работают только в личном чате с ботом.

| Команда | Что делает |
|---|---|
| `/status` | Работает ли отметка, когда была последняя проверка и отметка |
| `/pause` / `/resume` | Временно остановить / снова включить отметку |
| `/password <новый пароль>` | Обновить пароль KBTU в `users.json`. Бот сразу удаляет сообщение с паролем |
| `/stop` | Отвязать чат: отметка продолжается, но сообщений больше не будет |

Если у одного человека несколько аккаунтов, добавь логин: `/pause student1`, `/password student1 новыйпароль`.

### 4. Запуск

Дважды кликни `start.bat` — откроется консоль с логами.

## Автозапуск при включении ПК (Task Scheduler)

Чтобы скрипт запускался автоматически при загрузке Windows (даже без входа в систему):

1. Открой **Task Scheduler** (Win + R → `taskschd.msc`)
2. Нажми **Create Task...** (не Basic Task)
3. Вкладка **General**:
   - Имя: `KBTU AutoScraper`
   - Выбери **Run whether user is logged on or not**
   - Поставь галочку **Run with highest privileges**
4. Вкладка **Triggers** → **New...**:
   - Begin the task: **At startup**
5. Вкладка **Actions** → **New...**:
   - Program: `C:\путь\к\репозиторию\AutoScraper\venv\Scripts\python.exe`
   - Arguments: `open_kbtu.py`
   - Start in: `C:\путь\к\репозиторию\AutoScraper`
6. Нажми **OK**, введи пароль Windows

Скрипт будет запускаться при каждом включении ПК — без WSL, без Docker, без входа в систему.

## Установка на сервер (Linux)

На Ubuntu/Debian из папки репозитория:

```
sudo ./install.sh
```

Скрипт ставит часовой пояс Asia/Almaty (от него считается `ACTIVE_HOURS`), зависимости и Chromium, при нехватке RAM добавляет swap и регистрирует systemd-сервис `autoscraper`. Логи: `journalctl -u autoscraper -f`. Остановка: `sudo systemctl stop autoscraper`.

Не запускай одновременно сервер и Windows-версию с одним токеном бота: Telegram отдаёт сообщения только одному из них, а отметка будет идти дважды.

## Логи

Логи записываются в папку `logs/autoscraper.log` (ротация: макс 5 МБ, хранится 3 файла).

## Как это работает

1. Загружает и проверяет `users.json` и `.env` (при ошибке пишет, что не так, и останавливается)
2. Запускает headless Chromium через Playwright
3. В активные дни и часы каждые 35 секунд открывает портал; если сессия истекла — логинится заново
4. Находит кнопку "Отметиться", нажимает и ждёт, пока она исчезнет — только тогда шлёт "ATTENDANCE MARKED" в Telegram
5. Уведомления и команды — через Telegram-бота, каждому лично (см. выше)
6. При ошибке перезапускается с нарастающей задержкой (до 5 мин). В Telegram приходит одно сообщение о проблеме (повтор — не чаще раза в час) и одно — когда всё снова работает
7. Если падает сам браузер — перезапускает его
